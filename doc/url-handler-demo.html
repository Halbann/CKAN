ckan:// test page

Test links for the ckan:// handler. Operations are defined in Core/IO/ProtocolRouter.cs. A running CKAN picks the URL over a pipe, otherwise a new one is launched.

focus

Highlight a mod in the list.

  • ckan://focus?mod=JNSQ
  • ckan://focus?mod=Astrogator

search

Apply a search filter. %40 is an escaped @ for author search.

  • ckan://search?q=engine
  • ckan://search?q=%40Nertea

install

Add one or more mods to the changeset. mod:version pins a version. A version missing from the registry falls back to latest compatible.

  • ckan://install?mod=RealSolarSystem&mod=ROEngines&mod=ROTanks&mod=ROCapsules&mod=ROSolar
  • ckan://install?mod=JNSQ:0.10.0&mod=Astrogator:1.0.0
